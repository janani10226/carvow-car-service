-------------------------------------
1. Double-click "Open_Admin_Portal.bat" inside this folder.
   OR open your browser and navigate to:

2. ADMIN LOGIN CREDENTIALS:

3. LIVE FEATURES IN ADMIN CONTROL CENTER:

   - Live metrics (Total Requests, Pending, Accepted, In Progress, Ready for Pickup, Declined).
   - Milestone Status Controls:
       * "Start Work" (In Progress)
       * "Mark Completed" (Ready for Customer Pickup)
       * "Update Status" (with custom technician notes)
   - Real-time email dispatch to customers on every status change.
   - Real-time live polling (auto-refreshes every 3 seconds).
